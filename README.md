# 🏛️ MemPalace Wanderer

A complete Hermes Agent skill for MemPalace — local-first AI memory with semantic search, knowledge graphs, and cross-domain tunnels. Single-file, drop-in, zero dependencies.

See [SKILL.md](SKILL.md) for the full guide: setup, protocol, tool reference, KG seeding (3-layer pattern), tunnel wiring, diagnostics, pitfalls, and troubleshooting.

## Quick Install

```bash
pip install mempalace
mempalace init
```

Add MCP config to your agent, copy `SKILL.md` into skills, load it. Details in the skill.
